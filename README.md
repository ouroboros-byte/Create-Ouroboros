# Create-Ouroboros

A Create Aeronautics focused modpack with select Create addons, enhanced worldgen, QoL, and performance tweaks.

Core content also includes Farmer's Delight, Aquaculture, and relevent addons/compats for processing and automation with Create machinery.

Terralith and Tectonic overhauled world generation with extended build limits. Vanilla structures have been largely replaced with structures from Terralith, Towns and Towers, and the YUNG's better structures mods.

The objective of making this modpack is to refresh the base game with content and mechanics that make mining, farming, and exploration more fun and rewarding while avoiding loading the game with an overwhelming amount of unnecessary or unbalanced blocks/items/mobs. Toward this end, and to avoid duplicates, many of the mods included in this pack have been configured so that some blocks, items, structures, and biomes are excluded from gameplay. This can be reconfigured as desired for singleplayer.

Voxy and Colorwheel compatible shaders are included. Textures replaced with Maffhew's Excalibur resource pack and a number of supporting resource packs (loaded as default) for visual improvement and cohesion across the majority of added content including Create, Farmer's Delight, and Aquaculture 2.

Distant Horizons is recommended as an alternative to Voxy for users without dedicated graphics, remember to remove or disable Voxy, Voxy Server Side, and Chunky.

Fun extras: Stardew fishing minigame, Gliders, Goblin Trader, Ribbits :)

8-12 GB allocated memory is recommended.

Java arguments: -XX:+UseZGC -XX:+ZGenerational -XX:+AlwaysPreTouch -XX:+UseStringDeduplication -XX:MaxRAMPercentage=90
